# Repository map: signalreason.com

## Purpose and local use

Single-page static marketing site for Signal & Reason LLC. Open `index.html`
in a browser. No package install or local build is needed.

## Files

| Path | Purpose |
| --- | --- |
| `index.html` | Page markup, service list, footer links, SVG icons, and inline CSS. |
| `img/logo-transparent.png` | Logo used by the page. |
| `CNAME` | Custom domain for GitHub Pages. Do not edit this file. |
| `README.md` | Local use, checks, hosting, and work tracking. |
| `AGENTS.md` | Repository instructions. |
| `.githooks/pre-commit` | Blocks staged additions and changes to `CNAME`. |
| `scripts/setup-git-hooks.sh` | Sets `core.hooksPath` to this repository's `.githooks` directory. |
| `schemas/prd.schema.json` | JSON Schema for task records. |
| `schemas/conventional-commit-message/` | JSON Schema and instructions for parsed commit messages. |
| `files/dev-command-cheatsheet.pdf` | Development command reference. |

The schemas are reference files. No automated schema validation is configured.

## Browser requests and links

- The browser loads the page and logo from the site.
- The page loads Water.css 2 from jsDelivr, with local style overrides in
  `index.html`. There is no Google Fonts reference.
- The footer links to the Signal & Reason GitHub and Telegram accounts.
- There is no JavaScript, backend, form submission, or booking integration.

## Checks and deployment

See [README.md](README.md) for local checks and the pull request workflow.
There is no configured local build, automated test suite, or Linux container
check.

GitHub Pages publishes the root of `main` to `https://signalreason.com/`, with
HTTPS enforced. GitHub manages the Pages workflow; the repository has no
`.github/workflows/` files. See the [Actions history](https://github.com/signalreason/signalreason.com/actions)
for build and deployment results.
